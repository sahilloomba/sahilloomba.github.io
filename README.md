# sahilloomba.github.io

Personal website, served by GitHub Pages at <https://sahilloomba.github.io>.

Plain static HTML/CSS — no build step. Edit `index.html` and `style.css`, commit,
and push to `main`; the live site updates within a minute or so.

## Editing checklist
- Fill in the real URLs for the `Google Scholar` and `CV` links in `index.html`
  (they currently point to `#`), or delete the ones you don't want.
- Drop a `CV.pdf` in this folder and point the CV link at `CV.pdf` to serve it.
